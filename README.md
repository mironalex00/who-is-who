# Quién es Quién: Con su Famoso Favorito

## Descripción
"Quién es Quién: Con su Famoso Favorito" es un juego interactivo en PHP inspirado en el clásico "¿Quién es quién?" en el que los jugadores deben adivinar la identidad de un famoso a partir de pistas y preguntas. Este proyecto pone a prueba tu capacidad de deducción mientras te diviertes con datos curiosos y características únicas de celebridades.

## Características
- **Preguntas Interactivas:** Genera preguntas dinámicas que ayudan a descartar o confirmar la identidad del famoso.
- **Validación de Respuestas:** Sistema que valida las respuestas y determina si el jugador ha acertado.
- **Código Modular:** Implementación orientada a objetos que facilita el mantenimiento y futuras expansiones.
- **Interfaz Amigable:** Diseño sencillo y responsive, fácil de usar en distintos dispositivos.

## Tecnologías Utilizadas
- **PHP:** Lenguaje de programación principal para la lógica del juego.
- **HTML/CSS:** Para la estructura y el diseño visual de la aplicación.
- **JavaScript (Opcional):** Para agregar interactividad y validaciones en el lado del cliente.
